Workflow canvas

      
Canvas controls
Select a capability to inspect its request. Select an output (or drag from it) and then a highlighted input to rebind it; hovering an output previews which inputs accept it. Port colour and shape name the contract (see Port types); a refused connection names both contracts. The Mapping chip on a card expands the protocol mapping from each source to its argument. Drag a capability heading to move it; Alt + arrow keys also move the selected capability. Optional inputs that are not connected are folded into an "optional inputs" row on each card; expand it to connect one. Fit to view, zoom and Arrange view change only what you see: saved positions change only when you move a card, review and save. Add a capability from the palette by clicking it or dragging it onto the canvas; remove the selected capability with Delete, its context menu or Remove capability in Selection.

    Save behavior
    Saving updates source for future New run captures. It does not launch a run or change existing captures. Task-bound publication checks the explicitly selected native task identity.
    
    
    Concurrent writers
    Cooperating API writers serialize saves. An external write after the final comparison may be overwritten and absent from recovery copies. Refresh after save shows observed current bytes.
