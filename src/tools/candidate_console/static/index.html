About the console token
  • What it is: a secret created by init that locks this console, so other users and programs on the same machine cannot start runs or read your data. It is not a model provider API key.
  • Where to find it: in the console-token file printed by init, check and serve (siderius_workspace/settings/console-token). Show it with cat on the machine that runs the console, then paste it here.
  • Local or remote: on your own computer, open the printed address directly. On a remote server, keep the server running there and open an SSH tunnel from your computer first (ssh -N -L 127.0.0.1:PORT:127.0.0.1:PORT YOUR_HOST), then open the same address locally.

Enter the console token again after reopening this page. It is kept only in this page’s memory.

Workflow canvas

      
Canvas controls
Select a module to see its inputs. Select an output (or drag from it), then a highlighted input to connect them; hovering an output previews which inputs accept it. The + beside an output adds a module that accepts it, already connected. Socket colour and shape name the connector type (see Connector types); a refused connection names both. Drag a module heading to move it; Alt + arrow keys move the selected module. Optional inputs that are not connected fold into a “+N optional” row. Fit to view and zoom change only what you see. Tidy up arranges the cards in left-to-right columns as one undoable edit. Check the workflow follows every connection in order and stops at the first break. Delete (or the module's menu) removes the selected module; Undo brings it back.
