Canvas controls
Select a capability to inspect its request. Select an output and then a highlighted input to rebind it. Drag a capability heading to move it; Alt + arrow keys also move the selected capability. Fit to view, zoom and Arrange view change only what you see: saved positions change only when you move a card, review and save.
