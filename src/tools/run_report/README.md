# src/tools/run_report

Run `.venv/bin/python -m tools.run_report` through [`__main__.py`](__main__.py)/[`cli.py`](cli.py) to read a
caller-selected workspace and render HTML/figures via `figures.py`. It reports
existing records and does not launch execution; focused CLI tests are under
[`test_step12_pr12e_run_report_cli.py`](../../../tests/unit/tools/test_step12_pr12e_run_report_cli.py).

See [the parent guide](../README.md) for child ownership and the focused validation route.
