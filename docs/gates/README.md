# Execution qualification

A Gate checks behavior that ordinary deterministic tests cannot establish,
such as a real provider call or a bounded training run. Read the
[Gate testing standard](gate_testing_standard.md) before planning one; it owns
scope, prerequisites, authorization and evidence requirements.

For normal source changes, start with [testing](../testing/README.md).
A passing unit suite and a successful scientific execution answer different
questions. Neither grants permission to launch a new experiment.
