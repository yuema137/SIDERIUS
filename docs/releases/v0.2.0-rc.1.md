# SIDERIUS v0.2.0-rc.1

This is a prerelease of the task-generic SIDERIUS framework. It identifies the
Python distribution as `0.2.0rc1` and records the corresponding lockfile
metadata. No execution, scientific, task, resource, retry, retention, or
provenance behavior changes in this prerelease.

## Scope

The package metadata and `uv.lock` root editable entry are synchronized. The
distribution payload remains framework-only: task compositions, plugins, and
external workflows supply scientific semantics at runtime.

## Pending gates

This prerelease is not a qualification or stable release. Real external
workflow qualification, the paired experiment-repository prerelease, exact-head
CI, issue closeout, and the remaining Step04/P0 acceptance evidence are still
pending. The companion `siderius-exp` repository must complete its
operator-approved TIDMAD qualification before a paired stable release is
considered.

## Release boundary

This artifact contains no dataset, workspace, credential, real-task, campaign,
or `.structured-coding` asset. It does not run a scientific campaign, contact
an external provider, or include secrets. Consumers must provide any task data,
workspace, credentials, and workflow configuration explicitly outside the
package.
