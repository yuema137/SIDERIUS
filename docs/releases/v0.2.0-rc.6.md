# SIDERIUS v0.2.0-rc.6

This is an immutable prerelease of the task-generic SIDERIUS framework. It
identifies the Python distribution as `0.2.0rc6` and records synchronized
lockfile metadata. External qualification remains pending; this is not a
stable release and does not claim scientific performance.

## Scope

Compared with `v0.2.0-rc.4`, this candidate additionally persists the typed
logical round on newly produced successful experiment records. Resume can
therefore report exact persisted round provenance for fresh records instead of
classifying them as legacy records with an unknown round.

Historical records that omit the field remain fail-closed as
`legacy_unknown`. The change adds no inference from list position, task name,
score ordering or manifest ordering, and it does not change Trial/Formal
selection, scoring, Health, resource admission, resume eligibility or any task
declaration.

The `rc.6` label intentionally skips an infra `rc.5`: the paired experiment
repository already used `rc.5` for an experiment-only workflow correction
while still depending on infra `rc.4`. Both repositories advance to `rc.6` so
the next qualification pair has one unambiguous shared label.

## Qualification status

The paired `siderius-exp` revision, fresh external-task workflow evidence,
remaining issue closeout and stable-release acceptance gates are still
pending. This prerelease must not be treated as stable or as evidence that a
scientific campaign is ready to launch.

## Release boundary

This artifact contains no dataset, workspace, credential, real-task package,
campaign state, scientific result or `.structured-coding` asset. Consumers
must provide task data, workspaces, credentials and workflow configuration
explicitly outside the package.
