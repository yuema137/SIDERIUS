# SIDERIUS v0.2.0-rc.2

This is an immutable prerelease of the task-generic SIDERIUS framework. It
identifies the Python distribution as `0.2.0rc2` and records the synchronized
lockfile metadata. Qualification remains pending; this is not a stable
release and does not change scientific or execution treatment.

## Scope

Compared with `v0.2.0-rc.1`, this candidate contains only:

- PR470: repository homepage README authority, with its documentation test;
- PR471: the generic opaque `health_gate_files` carrier for task-owned Health
  coverage;
- PR472: named `EXPLICIT_NONE` Health absence, which is accepted without
  resolving an optional task capability.

These changes are framework contracts and documentation/tests only. They add
no task, dataset, campaign, budget, metric, Health threshold, resource,
retry, retention, or scientific-result treatment.

## Qualification status

External task qualification, final workflow evidence, issue closeout, and the
stable release acceptance gates are still pending. This prerelease must not
be treated as stable or used to claim scientific performance. A paired
`siderius-exp` prerelease may depend on this exact candidate, but neither
prerelease implies that a campaign is ready to launch.

## Release boundary

This artifact contains no dataset, workspace, credential, real-task package,
campaign state, scientific result, or `.structured-coding` asset. Consumers
must provide task data, workspaces, credentials, and workflow configuration
explicitly outside the package.
