# SIDERIUS v0.2.0-rc.3

This is an immutable prerelease of the task-generic SIDERIUS framework. It
identifies the Python distribution as `0.2.0rc3` and records synchronized
lockfile metadata. Qualification remains pending; this is not a stable release
and does not change any task-owned scientific treatment.

## Scope

Compared with `v0.2.0-rc.2`, this candidate adds the generic run-scoped
projection of a composition-selected task-owned custom loss. Proposer,
implementor and tuner consume that projection through their shared compatible-
loss inventory without registering the task implementation globally.

The projection is content- and contract-pinned. Missing, changed or conflicting
implementations refuse before agent or training effects; byte-identical copies
at different locator paths are treated as the same implementation. Uncomposed
and globally registered loss discovery are unchanged.

This candidate adds no task, dataset, campaign, budget, metric, Health
threshold, resource, retry, retention or scientific-result treatment.

## Qualification status

External task qualification, final workflow evidence, issue closeout and the
stable release acceptance gates remain pending. This prerelease must not be
treated as stable or used to claim scientific performance. A paired
`siderius-exp` prerelease may depend on this exact candidate, but neither
prerelease implies that a campaign is ready to launch.

## Release boundary

This artifact contains no dataset, workspace, credential, real-task package,
campaign state, scientific result or `.structured-coding` asset. Consumers must
provide task data, workspaces, credentials and workflow configuration
explicitly outside the package.
