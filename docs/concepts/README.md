# Concepts: what SIDERIUS does with your task

Read these pages to understand the ideas behind a run before you configure one.
Read them in this order:

1. [What SIDERIUS is](overview.md): the research loop and what the agents and
   the deterministic core each do.
2. [Execution model](execution-model.md): what runs in a separate process, under
   what limits, and how the task's declarations reach it.
3. [Data paths](data-paths.md): how a task's data is read and how its training
   and evaluation subsets are built.
4. [Task package](task-package.md): what a task must provide.
5. [Objectives and metrics](objectives-and-metrics.md) and
   [Health gates](health-gates.md): how models are ordered and when a model is valid.

The [glossary](glossary.md) defines the terms, including *workflow* and
*orchestration*. See [the parent guide](../README.md) for the other documentation areas.
