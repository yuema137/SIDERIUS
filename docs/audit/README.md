# Point-in-time audits

**This directory is an archive, not a description of current behavior.**

The documents here preserve source inventories, documentation-gap findings,
CI parity investigations, and test-rubric assessments made at specific
revisions. Their paths, counts, and recommendations may have been superseded.
Use them as provenance for why a later change was made; verify every current
claim against landed source and tests.

Current user and developer documentation starts at
[`docs/README.md`](../README.md). Design and decision history has its own
archive index at [`docs/design/README.md`](../design/README.md).
