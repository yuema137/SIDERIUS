# Provider marks

These small SVG marks identify providers in the model qualification table.
They are bundled locally so the page does not depend on an image CDN.

Source: [LobeHub Icons](https://github.com/lobehub/lobe-icons/tree/8b7bbc433d38437fa2b0cca58ae896917162b812/packages/static-svg/icons),
revision `8b7bbc433d38437fa2b0cca58ae896917162b812`, under the included
[MIT license](LICENSE). Filenames match the upstream icons.

The logo paths are unchanged. Each SVG has a white rounded backplate, a padded
view box and an explicit dark foreground in place of `currentColor`, so marks
remain legible in both GitHub themes. Provider names also appear as text.
The marks identify services; they do not imply endorsement or qualification.
