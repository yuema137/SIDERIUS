## Overview

Optimizes hyperparameters for a given ML model architecture over N rounds.
Each round: LLM plan → resource check → train → infer → score → LLM reflect.

Supports three execution modes:
- **Trial**: sparse multi-file sampling for fast iteration
- **Formal**: full multi-file evaluation for definitive scoring
- **Single-file (legacy)**: single training file, original pipeline

**V19 PR 1 addition**: the tuner now accepts a chain-reconstructed
formal-incumbent reference and a coupling switch
(`enable_chain_incumbent_formal_gates`, default OFF). The chain
incumbent is always reconstructed and recorded; the two formal delta
gates consume it only when coupling is ON (`chain_incumbent + fixed_delta`).
OFF is not a fixed-`0.0` mode. Full contract:
`nodes/ml_hyperparameter_tune_agent/ml_hyperparameter_tune_agent.md`
under "Chain formal-incumbent reference".

## Config Files Generated Per Round

All configs are written to `{workspace}/configs/{run_name}/` before execution.
Every field is Pydantic-validated before being serialized.

| File | Schema | Generated by | Consumed by |
|------|--------|-------------|-------------|
| `trial_config_{exp_id}.json` | `TrialConfig` | Agent loop | Traceability (not consumed by subprocess) |
| `model_config_{exp_id}.json` | Model Pydantic config | Executor (`execute_training`) | Training subprocess, Inference subprocess |
| `train_config_{exp_id}.json` | `TrainConfig` | Executor (`execute_training`) | Training subprocess |
| `loss_config_{exp_id}.json` | `LossConfig` | Executor (`execute_training`, `execute_inference`) | Training subprocess, Inference subprocess |
| `train_sample_set_{exp_id}.json` | `validate_sample_set()` | Executor (`execute_training`) | Training subprocess |
| `eval_sample_set_{exp_id}.json` | `validate_sample_set()` | Executor (`execute_inference`) | Inference subprocess |

## Data Flow: Trial/Formal Mode

```
HyperparamTuningInput
  │
  ├── is_trial=True → trial_allowed=True → anchor map loaded
  │
  └── Per round:
        │
        ├── brain.plan() → raw dict
        │     ↓
        ├── ExperimentPlan.with_defaults() → validated plan
        │     ↓
        ├── Override chain: expert constraint → final-round constraint
        │     ↓
        ├── TrialConfig (validated, with seeds)
        │     ↓
        ├── build_sample_set(seed=sampling_seed) → eval_sample_set (data scope)
        │     ↓
        ├── [Step 0] Resource check
        ├── [Step 1] Training:
        │     eval_sample_set + train_portion + train_base_seed
        │       → TIDMADEpochDataset (subsampled per epoch, cross-file shuffled)
        │       → model weights updated
        ├── [Step 2] Inference:
        │     eval_sample_set → denoise all segments in scope
        ├── [Step 3] Scoring:
        │     eval_sample_set → score_vector() (parallel) → file_vector + scalar
        │     ↓
        ├── brain.reflect() → research memory
        │     ↓
        └── ExperimentRecord saved
```

## Reproducibility: Seeds

Every round generates two deterministic seeds stored in `trial_config_{exp_id}.json`:

| Seed | Derivation | Controls |
|------|-----------|----------|
| `sampling_seed` | `SHA-256(run_name + attempt) % 2^31` | Which PSD segments form the data scope (`build_sample_set`) |
| `train_base_seed` | `SHA-256(run_name + attempt) >> 31 % 2^31` | Per-epoch training subsample: epoch `n` uses `train_base_seed + n` |

**Option A: Replay via the agent (easiest)**

Pass seeds from a previous run's `trial_config_{exp_id}.json` back to the agent:

```python
import json
from nodes.ml_hyperparameter_tune_agent import HyperparamTuningAgent
from agent.schemas.hyperparam_tuning import HyperparamTuningInput

# Read seeds from previous run
trial_cfg = json.load(open("trial_config_{exp_id}.json"))

agent = HyperparamTuningAgent()
output = agent.run(HyperparamTuningInput(
    model_type="punet",
    max_rounds=1,
    is_trial=True,
    # ... same config as original run ...
    # Inject seeds for exact reproduction:
    sampling_seed=trial_cfg["sampling_seed"],
    train_base_seed=trial_cfg["train_base_seed"],
))
```

When `sampling_seed` and `train_base_seed` are provided, the agent uses them
instead of auto-generating. When omitted (default `None`), auto-generation
from `SHA-256(run_name + attempt)` is used — same as before.

**Option B: Replay individual modules (manual)**

For lower-level control, call each module directly:

```python
# 1. Read configs
import json
trial_cfg = json.load(open("trial_config_{exp_id}.json"))
eval_ss = json.load(open("eval_sample_set_{exp_id}.json"))

# 2. Verify: rebuild eval_sample_set from seed (should match stored file)
from execute_tools.sample_set_builder import build_sample_set
rebuilt_ss = build_sample_set(
    is_trial=True,
    trial_strategy=trial_cfg["trial_strategy"],
    trial_portion=trial_cfg["trial_portion"],
    seed=trial_cfg["sampling_seed"],
)
assert rebuilt_ss == {int(k): v for k, v in eval_ss.items()}

# 3. Run training (via CLI)
# python execute_tools/train_engine_sandbox.py \
#     --model_cfg model_config_{exp_id}.json \
#     --train_cfg train_config_{exp_id}.json \
#     --loss_cfg loss_config_{exp_id}.json \
#     --sample_set_json eval_sample_set_{exp_id}.json \
#     --train_portion {trial_cfg["train_portion"]} \
#     --train_base_seed {trial_cfg["train_base_seed"]}

# 4. Run inference (via CLI)
# python execute_tools/inference_single.py --mode agent \
#     -m punet \
#     --model_cfg model_config_{exp_id}.json \
#     --loss_cfg loss_config_{exp_id}.json \
#     --model_path cached_models/model_punet_{exp_id}_agent.pth \
#     --sample_set_json eval_sample_set_{exp_id}.json \
#     --exp_id {exp_id} --run_name {run_name} \
#     --output_dir {workspace}

# 5. Run scoring (in Python — not yet a subprocess, see Phase 4c)
from execute_tools.scoring_utils import score_vector
from execute_tools.build_anchor_map import load_anchor_map
anchor = load_anchor_map("segment_anchors.json")
file_vector, scalar = score_vector(
    data_dir=workspace,
    sample_set=eval_ss,
    anchor_map=anchor["anchors"],
    s_max=anchor["s_max"],
    denoised_filename_fn=lambda fi: f"abra_validation_denoised_punet_{run_name}_{exp_id}_{fi:04d}.h5",
    raw_data_dir="/home/klz/Data/TIDMAD/",
)
```
